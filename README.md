# Jointspace

Joint Space Physiotherapy — offline, single-file assessment apps (open in any browser, works on phone).

| File | What it is |
|------|------------|
| `JointSpace-Assessment-v2.html` | General multi-joint assessment (shoulder, lumbar, knee, ankle, elbow, hand, neck, hip) |
| `JointSpace-Back-Assessment.html` | Detailed lumbar spine / SIJ / back assessment proforma |

## Back assessment proforma — contents

1. Patient details (auto BMI)
2. Chief complaint & history
3. Pain profile — body chart areas, NPRS sliders, 24-h behaviour, aggravating/easing, irritability
4. Red flags (cauda equina alert) & yellow flags
5. Medical, drug & social history
6. Outcome measures — full Oswestry Disability Index and Keele STarT Back with auto-scoring, plus RMDQ / FABQ / TSK / PCS / PHQ-9
7. Observation & posture, leg length
8. ROM for each movement — lumbar (flex, ext, side flex L/R, rotation L/R, quadrants) with AROM, overpressure, pain, end feel; Schober & fingertip-floor; thoracic; hip L/R active & passive; knee/ankle; McKenzie repeated movements
9. MMT for each muscle, L/R MRC grade with root level (lower limb + trunk); core endurance with McGill ratios
10. Muscle length & flexibility tests
11. Neurological exam — dermatomes L1–S5 (light touch & pinprick), myotomes, reflexes, UMN signs, neurodynamic tests
12. 50+ special tests with POS/NEG/N/A per side — neural/disc, facet, instability, stenosis, SIJ (Laslett cluster auto-scored), hip differentiation, Waddell signs (auto-scored), clinical prediction rules
13. Palpation & segmental PAIVMs / PPIVMs (T11–S1)
14. Investigations — detailed MRI (level-by-level disc, Pfirrmann, Modic, canal/lateral recess/foraminal stenosis, root, facets, listhesis, other structures, correlation), X-ray, lab tests, image uploads
15. Functional tests & PSFS
16. Clinical reasoning & diagnosis (ICF, pain mechanism, TBC), goals, treatment plan, sign-off

Records are saved on the device (IndexedDB) and can be edited, re-assessed, printed as a line-by-line report / PDF, and exported to CSV or JSON backup. An unsaved draft is kept automatically.
